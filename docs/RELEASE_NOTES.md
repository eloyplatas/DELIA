Delia 0.2.0: taller de cinta VST3 con los métodos de Delia Derbyshire.

**Novedades**
- Punto de inicio y de fin de lectura del carrete, en segundos o arrastrando sobre la forma de onda; doble clic para colocar el inicio.
- Preescucha de la región (como suena la nota 0) y regla para escuchar el fichero desde cualquier punto.
- Versiones VST3 para Linux, Windows y macOS (universal).
- Manuales en PDF en castellano e inglés.

**Descargas**
- `Delia-v0.2.0-linux-x86_64.zip`: Linux con glibc 2.35 o posterior.
- `Delia-v0.2.0-windows-x64.zip`: Windows 64 bits.
- `Delia-v0.2.0-macos-universal.zip`: macOS Intel y Apple Silicon (firmado ad hoc; ver el manual si el sistema lo bloquea).
- `Delia_Manual_ES.pdf`, `Delia_Manual_EN.pdf`.

Las versiones de Windows y macOS se compilan en GitHub Actions y no se han probado todavía en un anfitrión real.
